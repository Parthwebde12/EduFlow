# Security Policy

## Supported Versions

EduFlow is currently in active development. Security fixes are applied to the
`main` branch only.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in EduFlow (for example, an issue
related to authentication, JWT handling, data exposure, or file uploads),
please **do not open a public issue**.

Instead, report it privately:

1. Go to the repository's **Security** tab on GitHub and use
   **"Report a vulnerability"** (GitHub Private Vulnerability Reporting), or
2. Contact the maintainer directly via their GitHub profile.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested fix, if you have one

We will acknowledge your report as soon as possible and keep you updated as
the issue is investigated and resolved. Please give us reasonable time to
address the issue before any public disclosure.

Thank you for helping keep EduFlow and its users safe.
